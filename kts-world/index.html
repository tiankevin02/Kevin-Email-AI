SECOND LIFE ECONOMIC MMO

SECOND LIFE.もう一つの世界で、もう一つの人生を生きる。

KTS WORLDは、カジノだけを遊ぶゲームではない。働く、冒険する、投資する、土地を持つ、会社を作る、人を雇う、失敗する、破産する、再起する。プレイヤー自身が「この世界で何者になるか」を選ぶ、経済MMO × 人生シミュレーション。

DESIGN THESIS

このゲームの中心思想

資産ランキングだけを競うゲームにしない。時間、現実のお金、先行者利益のどれか一つで勝敗が固定されない世界を作る。

期待値は近く仕事・冒険・経営・予測・カジノで平均価値を近づける。
体験は遠く安定性、分散、判断力、拘束時間、一攫千金性は大きく変える。
張り付き ≠ 富長時間プレイは経験や人脈に効くが、無限にKTSを生まない。
課金 ≠ 成功現実のお金はLuxuryを買えるが、ChampionやCEOの成功そのものは買えない。
INTERACTIVE GAME DESIGN BIBLE

システム詳細

各項目をタップすると、目的・具体案・数値イメージ・他システムとのつながりまで確認できます。

成功を資産額だけで定義しない

プレイヤーには複数の「高み」を用意する。富豪だけが勝者になると、最効率の金策しか意味を持たなくなる。

ルート目指すもの主要な価値
Wealth大資産家KTS・土地・投資
Business巨大企業CEO会社・雇用・経営
CasinoHigh Roller / Champion勝負・技術・名声
Adventure伝説級冒険者探索・討伐・希少品
Analyst予測王知識・分析・情報販売
Political市長・国家指導者信用・人脈・統治
Collector歴史的資産の収集家限定品・称号・希少性
人生履歴をプロフィールに残す。「最高資産」「破産回数」「設立企業」「歴代役職」「獲得称号」などが、その人だけの物語になる。

KTSが欲しくなる理由

  • 土地・家・建築物・設備
  • 会社設立、Guild設立、事業投資
  • 装備、素材、カード、収集品
  • 大会参加、施設利用、サービス購入
  • 他プレイヤーへの給与、発注、取引

資産を4階層に分ける

階層例リスク
流動資産KTS・市場商品大きく失える
固定資産土地・家・会社持分価格変動・維持費
社会資本信用・人脈・役職行動で上下
人生資本スキル・実績・ストーリー基本的に残る
目標：「KTSがあるから遊ぶ」ではなく「この世界でやりたいことがある → だからKTSが欲しい」

基本単位は「時間」ではなくAction Energy

全員に一定量のEnergyを与え、各行動がEnergyを消費する。長時間オンラインだから新規KTSを無限に生成できる構造を防ぐ。

稼ぎ方期待値イメージ分散特徴
会社勤務約1,000 / 10E低安定、初心者向け
農業・製造約1,000 / 10E低〜中市場価格に左右
探索約1,000相当 / 10E中KTS＋素材＋レア品
起業長期平均は近似高経営判断で差
予測長期平均は近似中〜高知識・情報型
Casino基準近辺に調整極大一攫千金と破産

市場が短期EVを動かす

今週は鉄不足で採掘が有利、翌週は供給過多で農業が有利、というように短期では差を出す。しかしプレイヤーが高収益職へ移動すると供給が増えてEVが戻る。

長期：期待価値 ≒ Energy × 判断力 × リスク選択 × 経済状況
「期待値が同じ＝全部同じゲーム」ではない。安定して1万KTS得る人生と、±10万KTS動く人生はまったく違う体験になる。

Weekly Energy

DailyではなくWeeklyを中心にする。月曜にほとんど遊べなくても、土日にまとめて使える。

  • Weekly Energy例：700E
  • 未使用分の一部をEnergy Bankへ持ち越し
  • 72時間程度までRested Energyを蓄積
  • ログインしなかった人は復帰時に効率ボーナス

Routineは自動化、Decisionは自動化しない

自動化してよい本人が決める
農場の収穫、工場稼働、給与支払い、定期配送何を作るか、どこへ投資するか、誰と提携するか、土地を売るか

会社員プレイヤーが朝15分で指示を出し、現実の仕事中に工場が稼働。夜にレポートを確認し、次の意思決定をする。これなら「忙しい人が経営者になる」という世界観にも合う。

TIME SHOULD CREATE EXPERIENCES, NOT PRINT MONEY.
長時間プレイは知識、人脈、技術、物語では報われる。しかし新規KTS生成量は時間に比例させない。

食事による追加Energy

自然回復が公平な基礎。食事は追加回復だが、満腹度・消化時間・週間上限で無限行動を防ぐ。

料理AP追加効果例
パン+5なし
家庭料理+8Rest効率+2%
高級ステーキ+10採掘効率+5% / 2h
コース料理+12Social / Reputation系バフ

市場循環

農地 → 農家 → 食材 → 料理人 → レストラン → プレイヤー → AP消費 → 経済活動

高級料理はAP量を大幅に増やすより、便利さや短時間バフに価値を持たせる。富裕層が食料を買い占めて無限に行動できる状態を防ぐ。

ギャンブルの役割

Casinoは「最も効率よく稼ぐ方法」ではなく、「最も短時間で人生が激しく動く方法」。Poker、Blackjack、Baccarat、Slot、Tournamentなどを用意。

Risk Wallet

生活資金と賭け資金を分ける。カジノで直接使えるのはRisk Walletのみ。自分で追加移動はできるが、リスクを明示する。

Life Foundation

Starter Home、基本装備、職業ライセンス、ストーリー進行など最低限の人生基盤は賭博で消えない。

Casino Rank

新規プレイヤーは最大ベット額を制限。実績・信用・経験でHigh Roller卓を解放する。初日に全財産を一発で失う事故を抑える。

破産したら「再起編」が始まる

  • NPC企業への就職
  • 日雇い・配達・採掘・農業
  • Guild依頼、賞金PvE
  • プレイヤー企業からの求人
  • Comeback専用Achievement

破産 → 港湾労働 → 鉱山会社 → 貯金 → 小さな土地 → 起業 → 成功 → 再びHigh Roller、という人生そのものを物語にする。

救済＝元通りにKTSを配る、ではない。
損失の痛みは残しながら、「別の道から再び立ち上がれる」ゲームを用意する。

勝ち逃げも評価する

一定利益で退出するとDiscipline実績を付与。Safe Vaultへ利益を移すと一定時間カジノへ戻せないなど、「利益確定」もゲーム戦略にする。

所有権と収益権を分離

土地そのものの所有感は強く残す。一方、収益は土地 × 建物 × 人口 × 稼働率 × 経営 × 周辺環境で変動する。

土地収益 = 基礎価値 × 建物性能 × 稼働率 × 地域需要 × 経営効率 − 維持コスト

永久所有でも「持つだけ」では勝てない

  • 固定資産税
  • 建物維持費
  • 建物Decay（放置で性能低下）
  • 営業ライセンス / Development RightsのSeason更新
  • 災害・景気・人口移動による土地価値変動

新規プレイヤーのフロンティア

Seasonごとに新地域を開放。Tokyoの一等地を取れなくても、次のSingapore、Dubai、Moon Colonyなどで初期開拓者になれる。

新規専用Frontier Zoneは土地が安いがインフラが弱い。新規プレイヤーたちが企業・道路・店舗を集めることで大都市化し、土地価値が上がる。

理想は「土地を買った者勝ち」ではなく、「土地を上手く経営し、街を作った者勝ち」。

土地そのものは消さない

地震や台風で購入した土地そのものを喪失すると理不尽感が強い。建物耐久、生産能力、地域人口、物流などに段階的ダメージを与える。

イベント影響例
地震建物耐久-25%、生産-40% / 48h
洪水農地・物流へ大ダメージ
火災特定建物の修繕需要
好景気商業・観光需要増

災害が経済を動かす

地震 → 建物破損 → 建設需要↑ → 鉄・木材↑ → 保険金 → 復興投資 → 雇用↑

保険業

火災、地震、農業、店舗などの保険を作る。初期はNPC保険会社、成熟後はプレイヤー企業にも開放する。リスク評価や保険料設定自体が職業になる。

会社の種類

AgricultureMiningManufacturingRestaurantInsuranceInvestmentAdvertisingMediaCasino

雇用

CEO → Manager → Employeeなどの役職を持ち、給与・成果報酬・権限・設備利用などを設定。忙しいユーザーは会社に就職して安定収入、時間や判断力のあるユーザーは経営へ進む。

Discordと同期

ゲーム内でCompanyを設立すると、Discord側にもCompany Role・専用チャンネルを作成。採用や昇進でRoleを同期し、ゲーム内社会とコミュニティを一致させる。

冒険ループ

Explore → 資源 / Monster → 装備 / 素材 → Marketplace → 製造 / 強化 → より深い地域

鉱石、木材、食料、Rare Material、装備、カード、トロフィーなどを獲得。希少度はCommon / Rare / Epic / Legendary / Mythic / Unique。

Unique資産

世界に一つしか存在しない歴史的アイテムやSeason優勝トロフィーなどを作り、所有履歴や由来を価値にする。

PvP / Guild

PvP、Guild War、Company War、Season Championshipなど。ただし他人の課金土地を完全奪取するような設計は避け、税収・資源権・地域Buff・統治権などを争う。

Prediction

株価、指数、為替、商品、競馬・競輪などの現実データを題材にした予測ゲーム。Accuracy、連勝、難易度などでPrediction PointとAnalyst Rankを構築。

情報販売

プレイヤーは競馬予想、競輪予想、株分析、Poker戦略、土地価格分析などをゲーム内レポートとして販売できる。情報そのものを生産物にする。

実サービス化時、現実のお金や換金可能資産を賭ける仕組みとは分離し、予測ゲーム・ランキングとして設計する前提で法務確認する。

基本思想

Money can buy luxury. It cannot buy success.
豪華な第二の人生は買える。しかし、Champion、CEO、大統領、伝説の冒険者という成功そのものは買えない。

AI秘書

「鉄価格が昨日比12%上昇」「工場の夜間稼働率が低い」「倉庫在庫を売れば推定8,400 KTS利益」などを教える。忙しい人ほどPremium価値を感じる。

家・乗り物・社会的ステータス

Starter Apartment → Penthouse → Villa → Mansion → Castle。車、ヨット、Private Jetなども自己表現・所有欲に使う。他人を家へ招待できれば課金家具の価値も高まる。

Company Pro

無料会社は小規模。Proで大人数管理、KPI Dashboard、AI CFO、給与自動化、Discord Role同期など「経営の便利さ」を販売する。

避けたい課金

  • 現金で大量KTSを直接買って即富豪
  • Real Moneyガチャから最強装備
  • 課金額で政治力や選挙票が増える
  • 課金食料でAPを無制限回復

初心者AI

ARIAのような案内役が「一攫千金」「冒険」「頭脳派」など最初の目的を聞き、その人に合うコンテンツだけ順番に紹介する。最初から全機能を見せない。

AI Dealer

ARIA＝優しい、VICTOR＝挑発的、LUNA＝冷静、KING＝高圧的など人格を持たせ、Dealer自体をコレクション・Cosmetic商品にする。

AI経済

ローンチ初期は人口不足で世界が寂しくなるため、AI企業、AIショップ、AI住民を配置。プレイヤー人口増加に応じて人間経済へ置き換える。

NON-NEGOTIABLE PRINCIPLES

守るべきゲームデザイン原則

01｜失敗しても引退させない破産・失業・都市崩壊も次のストーリーの入口にする。
02｜時間を無限にKTSへ変換させない長時間プレイは体験、情報、人脈で報いる。
03｜先行者が永遠に勝たない税、維持費、Decay、災害、Season、新地域で機会を循環させる。
04｜期待値は近く、人生は違う安定職とHigh Rollerを同じ体験にはしない。
05｜課金で成功を買わせない課金はLuxury / Identity / Convenienceへ。
06｜社会をプレイヤーに作らせる会社、雇用、Guild、情報、政治、人間関係をUGC化する。
07｜新規ユーザーにも夢を残すFrontier、Season、Comeback、複数ランキングで後発にも頂点を用意。
08｜複雑さはAIとUIで隠す奥深い裏側を、初心者には「今日はこれをやろう」で見せる。
実サービス化について： 現金・換金可能資産を用いた賭博、トークン/NFT、景品・再販売、金融商品に近い仕組みは地域によって規制が異なるため、まず換金不可のゲーム内経済として設計し、リアルマネーや外部取引のレイヤーは別途法務確認を前提とする。
